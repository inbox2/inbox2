# inbox2 brand assets

Canonical source files for the inbox2 marks. Edit the SVGs; everything shipped in
the apps is rendered from these.

| Master | What | Where it ships |
|--------|------|----------------|
| `alt-icons/*.png` (sun, vennlight, graffiti, classic) | **App icons** — the four the user can choose between in Settings › Theme › App icon. `sun` is the default: it is what every platform's bundle ships, and on desktop it is what the Dock falls back to when the app quits | iOS (primary + `CFBundleAlternateIcons`), Android (`activity-alias` per icon), desktop (bundle `icons/` + `icons-dev/`, plus `icons/alt/` for the runtime switch), and the web picker previews. All generated by `python3 brand/make-alt-icons.py`. |
| `inbox2-mark.svg` (+ `inbox2-favicon-512.png`) | **Mark** — dark rounded "2" badge | Inline marks (`logo-mark.png`), unified-inbox avatar, website favicon, CLI, desktop OAuth page, iOS/Android `ch-unified`. Rendered full-bleed from `inbox2-icon-ring-two.svg`; the old `logo.png` / `channels/inbox2-box.png` (flat "2", no ring) are gone. The **web app's** favicons (`favicon.ico/-32/-128/-512`) are NOT from this mark any more — they follow the default app icon, written by `make-alt-icons.py`, so the browser tab and Web Notification popups match the icon everywhere else. That script also writes Android's `ic_launcher_monochrome` (themed icon + notification status-bar glyph) as a sun silhouette. |
| `inbox2-tray-template.svg` | **Menu bar glyph** — the app-icon box in one colour, the 2 knocked out. Template image: only alpha matters, macOS tints it | Desktop tray icon. `rsvg-convert -w 72 -h 72 brand/inbox2-tray-template.svg -o ui/desktop/src-tauri/icons/tray-template.png` |
| `inbox2-wordmark-dark.svg` | **Wordmark**, dark ink → light backgrounds | Website footer (`Brand tone="dark"`). |
| `inbox2-wordmark-light.svg` | **Wordmark**, white ink → dark backgrounds | Website header + hero (`Brand`). |

## Legacy cube (kept on purpose)

The original glossy "inbox2 box" cube is **not** retired everywhere — it's kept for
nostalgia in three spots, served from in-repo assets (not this folder):

- **iOS launch screen + onboarding** — spinning turntable `ui/ios/Resources/inbox2-rotate-sheet.png`.
- **Web chrome tab** (Unified-inbox) — spinning `UnifiedCubeIcon` over `ui/web/public/inbox2-rotate-sheet.png`.
- **Web empty states** — static `ui/web/public/logo-cube.png` (Command Center, unified-inbox empty, list placeholder).

## Regenerating

**App icons** — `python3 brand/make-alt-icons.py` from the repo root. Drop a 1024
master in `brand/alt-icons/`, re-run, and it writes every platform. It is the ONLY
generator for these files: `make-app-icons.py` used to write the same paths from the
venn design and the two fought over them, which is how the desktop bundle ended up
shipping a mark that wasn't even in the picker. Adding an icon also needs wiring in
`AppIconOption` + `project.yml` (iOS), `AndroidManifest.xml` (activity-alias),
`app_icon.rs` and `appIcon.js`. Needs `rsvg-convert`, ImageMagick and `iconutil`.

The gradient rim comes from `RINGS` in that script — each icon's stops are drawn
from its own palette, and the masters stay rim-free so a re-run never stacks two.

**Everything else** — render the SVG to the sizes each platform needs with
`rsvg-convert` + `magick` (full-bleed for favicons). App-icon tiles are flattened
opaque (no alpha) per Apple's HIG; favicons/marks keep transparency.
